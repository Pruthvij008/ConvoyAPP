# Screenshots

Drop PNGs here with these exact filenames and the main README will pick
them up:

    map.png           the live trip map, a few cars visible
    stops.png         the "why have you stopped?" picker
    navigation.png    navigation mode, tilted and following
    lobby.png         the pre-trip lobby with the roster
    chat.png          chat with quick messages
    sos.png           an alert or the SOS overlay

Portrait, and roughly 1080x2400 straight off a phone is fine — GitHub
scales them down in the table.

To capture from a connected device or emulator:

    adb exec-out screencap -p > map.png
